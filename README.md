# Desafio-Phishing-DIO
## -------------------------PASSO A PASSO ATAQUE PHISHING----------------

1º Iniciar VM kali;

2º Iniciar Terminal como root (sudo su);

3º Iniciar a ferramenta setoolkit (setoolkit);

4º No menu, selecionar a opção (Social-Engineering Attacks);

5º (Website Attack Vectors);

6º (Credential Harvester Attack Method);

7º (Site Cloner);

8º Leia com atenção o aviso que aparecerá, talvez seja necessário realizar alguns ajustes na sua rede para continuar o processo;

9º Em seguida, será necessário informar o ip que será seu servidor do site clonado para receber as requisições;

10º Coloque o endereço http que você deseja clonar (você também pode importar uma página que você criou utilizando a opção custom import que fica no mesmo menu do passo 7º);

11º Mantenha o terminal do Setoolkit aberto para receber as requisições;

12º Para finalizar o processo e gerar os Logs registrados utilize Ctrl + C;

13º Obs: para verificar os logs salvos acesse o seguinte diretório (/root/.set/)
